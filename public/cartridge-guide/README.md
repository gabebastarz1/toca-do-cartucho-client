# Imagens do Guia de Cartuchos

Coloque as imagens de exemplo aqui para o guia de identificação de cartuchos.

## Estrutura de arquivos sugerida:

- `original-front-label.jpg` - Etiqueta frontal de cartucho original
- `original-back-label.jpg` - Etiqueta traseira de cartucho original
- `original-screws.jpg` - Parafusos Gamebit originais
- `original-internal.jpg` - Placa interna de cartucho original
- `repro-front-label.jpg` - Etiqueta frontal de cartucho repro
- `repro-back-label.jpg` - Etiqueta traseira de cartucho repro
- `repro-screws.jpg` - Parafusos comuns de cartucho repro
- `repro-internal.jpg` - Placa interna de cartucho repro
- `comparison-side-by-side.jpg` - Comparação lado a lado

## Formato recomendado:
- Formato: JPG ou PNG
- Tamanho: Máximo 800x600px
- Peso: Otimizado para web (< 200KB por imagem)
